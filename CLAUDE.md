# CLAUDE.md: Incident Runbook

Incident Runbook: quick-reference on-call response runbooks (runbook.neorgon.com)

**Live:** runbook.neorgon.com · **Port:** 8844

## Run

```bash
make serve
```

Then open http://localhost:8844. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

No persisted state: everything lives in memory for the session.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
